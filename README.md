# Chunran Zhang

Personal academic website · [ln-one.github.io](https://ln-one.github.io/)

Built with Jekyll and Jekyll Scholar. Requires Ruby 3.4+ and Bundler.

```sh
bundle install
npm run dev      # http://127.0.0.1:4321/
npm run build
npm run check
```
