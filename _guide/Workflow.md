**Markdown → LaTeX → Prism → Markdown.**
## 1. Research and drafting

Codex works on Markdown drafts, code, experiments, and references in a Git repository for version control and collaboration. Use Obsidian to read and edit Markdown. Keep plans, decisions, and results in project files for continuity across sessions.

## 2. Figures and formatting

Codex prepares figures following [[Figures]] and generates LaTeX from Markdown, then compiles with the references and publication template. Sources stay in Git for version control and collaboration. Markdown owns content; LaTeX owns layout.

## 3. Collaborative revision

Import the LaTeX project into Prism for coauthor and AI editing with live PDF previews. Prism becomes the main manuscript; pause content edits in the repository.

## 4. Return to the repository

Export from Prism. Codex reconciles content into Markdown and layout into LaTeX, checks the diff, and rebuilds. Save the reconciled version in Git; Markdown resumes as the main manuscript.
